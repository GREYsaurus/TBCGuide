# tools/build.ps1 lint fails on any global read that is not a Lua builtin, one of our own
# globals, or listed here. Adding a line is a deliberate decision: note its status.
#
# Status legend (from developer knowledge of the 2.5.x Classic client; NOT verified in-game):
#   core      - present since the original 1.x/2.x API and in all Classic clients
#   classic   - modern-API function present in the Classic (1.13+/2.5+) clients
#   guarded   - may be missing in some builds; every call site checks it exists first
#   optional  - provided by another add-on; always nil-checked
# Run /tbcg debug api in the client to confirm availability.
